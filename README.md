# Raspberry Pi Linux Operations

## Project Overview
This project documents my journey building and managing
a Linux workstation using a Raspberry Pi 5.

## Project Goals
- Learn Linux system administration.
- Configure secure remote access using SSH.
- Practice networking and troubleshooting.
- Develop Python automation skills.
- Learn Git and GitHub.

## Hardware and Software
- Raspberry Pi 5 (8 GB RAM)
- Raspberry Pi OS
- Windows laptop
- SSH

## Current Progress
- Raspberry Pi OS installed and configured.
- SSH enabled and tested.
- Remote Linux connection established.
- Practicing Linux file management.



## Practical Exercises Completed

### Linux File Permissions
- Investigated a simulated file-permission misconfiguration.
- Used `ls -l` and `stat` to inspect permissions.
- Corrected permissions from `644` to `600` using `chmod`.
- Verified the remediation and documented the findings.

### SSH Service Administration
- Configured and used SSH for remote Linux administration.
- Used `systemctl` to inspect the SSH service state.
- Reviewed service logs using `journalctl`.
- Practiced distinguishing service failures from their possible causes.
